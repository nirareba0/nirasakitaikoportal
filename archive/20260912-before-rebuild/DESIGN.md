# DESIGN

## 技術選定
- 素の HTML5 / CSS3 / vanilla JS のみ。フレームワーク・ビルドツール無し
- 理由：GitHub Pages にそのまま置けて運用コストが最小。更新も直接編集で済む
- 共通ヘッダー/フッターは各HTMLファイルに直接記述する（ビルド無しで include できないため）。将来ページが増えて重複が辛くなったら Eleventy 等の検討をADRに起こす

## ページ構成
| ファイル | 内容 |
|---|---|
| `index.html` | トップ。ヒーロー（部の一言紹介）、直近ニュース3件、代表動画1本の埋め込み、各ページへの導線、SNSリンク |
| `about.html` | 紹介・沿革。2001年創部の経緯、天野流・窮理居敬の精神、現在の活動概要（年間20件近くの依頼） |
| `videos.html` | 動画ギャラリー。鍛麗シリーズ・芸文祭演目をYouTube埋め込みでカード一覧表示 |
| `news.html` | 実績・お知らせ。学校サイトの記事一覧を時系列で（大会結果・演奏会告知など） |
| `links.html` | リンク集。Instagram／YouTube／学校公式サイト／韮崎文化ホールのイベントページへの外部リンク |

## データの扱い
- 動画は YouTube の `<iframe>` embed（`https://www.youtube.com/embed/<videoId>`）を直接使用。サムネイルは埋め込みプレイヤーが自前で表示するため画像を別途保存しない
- 学校公式サイトの写真ファイルはハンドリングしない（無断転載回避）。ビジュアルはCSSベースの装飾（和柄モチーフ・太鼓のシルエットなど）と埋め込み動画のサムネイルで構成
- 外部リンクは REQUIREMENTS.md の「確認済み事実」に列挙したURLのみを使用

## デザイン方向性
- 和太鼓・和のモチーフ：藍色/墨色をベースに、差し色として朱色または金色（演奏会ポスター等でよく使われる配色をイメージ）
- 見出しは力強い印象のフォント、本文は可読性重視のゴシック体
- テンプレート感を避け、太鼓の「バチ」「輪」等をあしらったシンプルな幾何学装飾を検討
- スマホ幅(400px)から破綻しないレスポンシブレイアウト。ナビはハンバーガー等で畳む

## 既知の制約・注意
- Instagramの内容は自動取得できない前提で、埋め込みはせず「Instagramで見る」の外部リンクのみにする
- 学校公式サイトはWordPress運営のため記事URLが将来変わる可能性がある。リンク切れ時は上位の `/bukatudo/taiko/` に差し替える
