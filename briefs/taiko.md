# 制作ブリーフ
## 主対象と仮説
主対象: SNSで部を知り、演奏をもう少し見たい地域の人。既存要件とユーザーの入場体験重視から選定。
以下は利用動機の設計仮説であり、実在する取材対象・調査結果ではない。
| 候補 | 不安/求めるもの | 対応 |
|---|---|---|
| 地域の初見の人（主） | どんな演奏か知らない | 写真とすぐ見られる動画 |
| 保護者 | 公式と混同したくない | 非公式表示と出典 |
| OB/OG | 今の活動に辿りたい | 最新の確認済み記事 |
| 公演の観客 | 次回公演を探す | 過去と最新情報導線の分離 |
| 中学生 | 部の雰囲気を知りたい | 実写真と紹介 |
| 中学生の保護者 | 連絡先の正確さ | 学校公式へのリンク |
| 和太鼓の愛好家 | 演目を探す | タイトルの明確な動画一覧 |
| 地域主催者 | 活動実績を知りたい | 実績と公式情報 |
| SNSを使わない人 | ログインせず把握したい | 本文の自立とYouTube外部リンク |
| 動きが苦手な閲覧者 | 落ち着いて読みたい | reduced-motionと即時表示 |

## 4視点の設計監査
- 導線: 最初の画面から演奏を見る。埋め込み失敗時も外部リンク。
- 表現: 太鼓イラストの定型を避け、本物の舞台写真が署名になる。
- 当事者: 投稿の冗談・人物特定・推測の部内情報を使わない。
- 運営: 非公式表示、原本保存、出典台帳、過去告知の扱いを明確化。
2周目の確認: 演出待ちと動画自動再生は見送り、初期読み込みと本人の操作を優先。
